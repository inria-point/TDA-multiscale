# Каталог пертурбаций (нарезка `base`)

Сдвиг d в процентах против неизменённого человеческого текста, парно по одним и тем же текстам. Полоса — среднее относительного сдвига по своему диапазону q:

* **крупный** — `q_small`, среднее по q >= 0.5
* **мелкий** — `q_large`, среднее по q >= 0.6
* **средний** — `q0.5_range`, среднее по q >= 0.3

`q_small` отбрасывает q самых коротких рёбер MST и оставляет длинные, `q_large` наоборот, `q0.5_range` — окно шириной 0.5.

Жирным выделено превышающее 3%: ниже этого порога сдвиг не отличается от шума прогона.
