# Датасет: галлюцинации в пяти версиях

56 вопросов из длиннохвостых предметов MMLU, ответы Qwen2.5-1.5B-Instruct
длиной 400–650 слов. Из каждого ответа сделаны версии, различающиеся по одному
признаку за раз.

| файл | версия | выдуманность | гладкость |
|---|---|---|---|
| `halluc_raw.json` | как сгенерировано | 6.9 | 5.5 |
| `halluc_polished.json` | язык переписан, факты те же | 6.9 | 7.8 |
| `halluc_chained.json` | факты исправлены поверх гладкой | 1.6 | 8.9 |
| `halluc_absurd.json` | те же фразы, факты абсурдны | 10.0 | 9.0 |
| `halluc_fixed.json` | правка прямо из исходника (первая, отвергнутая схема) | 1.4 | 8.8 |

Цепочка `raw → polished → chained → absurd` меняет по одному за шаг, поэтому
контрасты чистые. Ветка `fixed` — сестра `polished`, а не звено цепи; она
сохранена, но для выводов не годится.

Оценки судьи и обоснования: `halluc_scores.csv`.
Вопросы и эталонные ответы MMLU: `halluc_questions.csv`.
Девять вопросов (`q007 q010 q011 q013 q023 q032 q033 q035 q047`) выбрасываются
в анализе: генерация ушла в китайский.

## Повторить на другом эмбеддере

Тексты не зависят от эмбеддера, поэтому достаточно:

```
EMBED_MODEL=<hf-id> python experiments/halluc_qphd.py
EMBED_MODEL=<hf-id> python experiments/halluc_result.py
EMBED_MODEL=<hf-id> python experiments/absurd_edges.py
```

Ключ кэша эмбеддингов включает имя модели, так что старый прогон не
затирается.

## Что показал ModernBERT-base

Контрасты по крупной полосе:

| шаг | сдвиг | p |
|---|---|---|
| полировка языка | +1.7% | 0.21 |
| исправление фактов | +0.3% | 0.85 |
| замена фактов на абсурд | **−9.0%** | <0.001 |

То есть на этом эмбеддере правдоподобная выдумка неотличима от правды, а
бессмыслица отличается уверенно. Гипотеза для повторения на более сильном
эмбеддере: граница проходит по разрешающей способности — «BRCA2» против
«BRCA1» для ModernBERT-base неразличимы, «ген» против «погоды» различимы.
