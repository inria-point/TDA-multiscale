# Сессия 20–21 сентября 2026: геометрическая модель полос

Состояние на конец сессии. Документ самодостаточен: по нему можно продолжить
работу, не восстанавливая контекст из переписки.

## Что было на входе

К началу сессии уже было известно: облако эмбеддингов устроено как «каркас +
ячейки», три полосы размерности отвечают разным свойствам текста, сток внимания
надо выбрасывать. Была теорема о ячеечном облаке (`report_1.pdf`) с точкой
расщепления q*, и модель крупной полосы на каркасных величинах, которая
ошибалась знаком на перемешивании.

Задача сессии: довести геометрическую модель до состояния, пригодного для
статьи, и объяснить перемешивание.

## Что сделано

### 1. Полосы пересчитаны без стоков

`curve_vs_frame.py` → `results/bands_nosink.csv`. Все прежние полосы считались по
выборке, включавшей стоковые токены (флаг стока исключал их только из масштаба и
радиуса, но не из дерева). Сток-свободные и загрязнённые версии коррелируют на
0.985–0.997, но без стока контрасты на 11–15% сильнее. **Вся основная линия
теперь на `bands_nosink.csv`.**

### 2. Перемешивание в абсолютных единицах — это два эффекта

`shuffle_absolute.py` → `results/shuffle_absolute.csv`. В долях масштаба
перемешивание выглядит как «ячейки раздулись на 17%». В единицах эмбеддинга
видно, что это две вещи: радиус ячейки **+5.0%** и каркасное ребро **−6.1%**
одновременно. Обе толкают r/δ в одну сторону (+11.8%), поэтому в нормированных
единицах сливались.

### 3. Страты рёбер: длинный конец одиночечный

`edge_strata.py` → `results/edge_strata.csv.gz` (390 тыс. рёбер). Каждое ребро
MST отнесено к страте по кратности типов на концах. Выше 80-го перцентиля длины
**88.3% рёбер имеют хотя бы один разовый конец**, 55.5% — оба, при доле одиночек
45.9% (случайность дала бы 21%). Переход ячеечные → каркасные приходится на
30–40-й перцентиль — третий независимый замер той же границы.

Информация сидит не там, где больше рёбер: страта «одиночка–ячейка» (33% рёбер)
даёт r = −0.79 по CV против −0.47 у пар одиночек (50% рёбер).

### 4. Итоговая модель

Крупная полоса предсказывается четырьмя величинами, **R² = 0.91**:

    крупная = +0.02·радиус + 0.15·одиночек + 4.37·(черешок ср) − 0.53·(черешок CV) − 0.58

где черешок — ребро страты «одиночка–ячейка» в верхней полосе q ≥ 0.8.
Мелкая полоса — по одному радиусу (R² = 0.83), средняя — по одной доле одиночек
(R² = 0.85). Соответствие ручек и полос почти диагональное.

Согласие знака на содержательных сдвигах (|набл| > 3): крупная 94%, мелкая 91%,
средняя 96%.

### 5. Две гипотезы опровергнуты

**Анизотропная деформация каркаса** (`shuffle_synthesis.py`). Класс-зависимый
снос вдоль оси потери смысла измерен верно (разность крайних классов 0.20 при
каркасном ребре 0.76, все p = 4·10⁻¹⁸), но геометрически инертен: синтетика даёт
+0.2% при наблюдаемых −12.9%. Сдвиг вдоль одной оси из 24 входит в дистанции
квадратично. **Ось — маркер процесса, не механизм.**

**Альтернативный набор на двух стратах** (R² 0.90, точное попадание в
перемешивание). Отвергнут: страты коллинеарны (r = 0.952 по средним, VIF до
16.8), вне выборки преимущества нет — LOO R² 0.82 против 0.81. Точное попадание
оказалось артефактом подгонки.

### 6. q* пересчитан без стоков

Через число внутриячеечных рёбер (N = L − их количество). Исходный текст:
**q\* = 0.368** вместо 0.394. Поправка систематическая (−0.011 в среднем,
максимум −0.021), корреляция двух версий 0.9986. Следствие: эхо ×2 уходит на
0.497, и условий с q* > 0.5 остаётся три, а не четыре.

## Главный файл

`results/GEOMETRY_SUMMARY.md` — черновик краткого изложения геометрической части
по плану `../plan_geometry.md`, 11 параграфов с таблицами. §0 фиксирует условия
всех замеров, §9 перечисляет шесть мест, где план пришлось поправить.

`results/perturbation_table.csv` — 26 пертурбаций, для каждой полосы наблюдение
рядом с предсказанием, плюс все геометрические величины и q*.

## Что осталось

- **Настоящая версия для статьи.** Черновик проверен по числам, логика сходится.
- **β закона Хипса без стоков** не пересчитан (`heaps_beta.py` считает со стоком).
- **Мелкая полоса неполна** там, где пертурбация правит словарь напрямую: «ни
  одного слова дважды» (+6.5 при модели −6.5) и «беднее словарь» (−3.5 при +5.8).
  Радиуса недостаточно, когда меняется состав типов, а не их разброс.
- **Эхо ×4** — крупнейший промах (остаток −6.5) и условие с максимальным
  q* = 0.643. Оговорить как границу применимости.
- Переименовать синтетические операции в коде на «раздвинуть всех / утопить
  часть / спарить» (предлагалось, не сделано).
