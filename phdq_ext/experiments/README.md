# Эксперименты по подбору параметров

Здесь лежит то, чем выбиралась конфигурация оценки из
[`../scripts/config.py`](../scripts/config.py). Основной код счёта — в
[`../scripts/`](../scripts/); эти скрипты его только вызывают с разными настройками
и сравнивают качество.

Запускаются из корня `phdq_ext/`:

```bash
.venv/bin/python experiments/variant_sweep.py
```

Результаты пишутся в `../results/`, графики в `../figures/`.

| скрипт | вопрос | ответ |
|---|---|---|
| [`variant_sweep.py`](variant_sweep.py) | какие настройки снижают шум | без возвращения + широкий пул + 32 повтора: шум 0.114 → 0.026 |
| [`summarize_variants.py`](summarize_variants.py) | сводка по перебору | — |
| [`variance_decomp.py`](variance_decomp.py) | сколько в разбросе шума, а сколько различий текстов | разложение $\sigma_w$ / $\sigma_b$ |
| [`exp_grid_alignment.py`](exp_grid_alignment.py) | можно ли избавиться от округления выбором сетки | да, но дробная обрезка нужна всё равно; `round` вместо `floor` не спасает |
| [`length_sweep.py`](length_sweep.py) | как d зависит от L | $d \sim L^{-0.21}$, не сходится, настройкой не лечится |
| [`exp_length_policy.py`](exp_length_policy.py) | абсолютный L или доля от длины текста | только абсолютный; доля возвращает зависимость от длины |
| [`exp_L_per_q.py`](exp_L_per_q.py) | надо ли менять L вместе с q | не надо: лишает ось q интерпретации, а шум уже снят иначе |
| [`inspect_extremes.py`](inspect_extremes.py) | чем отличаются тексты с высокой и низкой d | структурной повторяемостью, не лексикой |

Подробные выводы с числами — в [`../README.md`](../README.md), раздел «Что выяснили».
